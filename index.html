The rules these bots play by

  • After every move that changes the board, one new tile appears in a random empty cell: a 2 with 90% probability, a 4 with 10%.
  • A move that changes nothing is not allowed, and no tile appears.
  • The game ends when no move changes the board, even if the board is not full until then.
  • Each board is stored as a 64-bit value (4 bits per cell), and each move uses precomputed row tables. This lets the search bots look at millions of positions per move.

Random and Greedy are the original bots from the 2022 C# version of this project (StupidBot and ehBot). The expectimax heuristic follows nneonneo/2048-ai.
